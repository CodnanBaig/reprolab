# Workbench surface
Mode: Operate. Audience: a developer trying to understand a real browser failure.
## Direction contract
THESIS: Evidence should occupy the workspace, not decorative analytics. Refuse vanity metric dashboards.
OWN-WORLD: White and cool-gray working surfaces, slate navigation, restrained ultramarine actions, red only for failures. System UI typography; monospace only for selectors, event time and source code.
STORY: Find a session, play the visual sequence, select an error and export a test.
FIRST VIEWPORT: A narrow navigation rail, contextual header and large two-pane evidence workspace; session inbox on the left, replay above a searchable event timeline on the right. Primary Record action stays in the top-right.
FORM: Developer debugging workbench. The concept launcher was unavailable; this is an explicit code-led fallback, not a generated seed assignment.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
